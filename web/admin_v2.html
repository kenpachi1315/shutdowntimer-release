Security Center

Configure Windows restrictions globally, then customize individual workstations when needed.

Server + Windows guard
Maintenance mode behavior: When an administrator enters Maintenance Mode on a workstation, all PisoNet-managed restrictions are temporarily lifted on that PC. Pressing LOCK reapplies its saved security policy. The Windows client guard restores the saved policy when maintenance ends. Restrictions are best-effort and can be bypassed by a local Administrator.
